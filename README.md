# AuraRadiance

A **Hollow Knight** mod for Absolute Radiance.

## Credits & Base Code
This project is built using the **AnyRadiancePrime** source code as a base. Special thanks to Early.

## Requirements & Dependencies
To ensure the mod runs correctly or to compile the source code, the following libraries are required in your development environment and the game's `Mods` folder:

* **Satchel**
* **ModCommon**
* **SFCore**

## Installation (For Developers)
1. Clone this repository.
2. Ensure that the assembly references (`.dll`) in the `.csproj` file correctly point to your Hollow Knight installation folder.
3. Build the project using Visual Studio or via `dotnet build`.
